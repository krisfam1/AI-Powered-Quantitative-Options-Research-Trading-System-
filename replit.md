# Python Script Workspace

A minimal Python environment for backend scripts, data processing, and experiments.

## Run & Operate

- `python main.py` — run the starter script
- Add project dependencies to `requirements.txt`
- Use the Run button to execute the script

## Stack

- Python 3.11
- Standard library only to start

## Where things live

- `main.py` — script entry point
- `requirements.txt` — Python dependencies

## Architecture decisions

- The project starts with the Python standard library only.
- `main.py` exposes a `main()` function so it can grow into a reusable script cleanly.

## Product

This is an intentionally blank backend/data workspace. Add scripts and dependencies as the project grows.

## User preferences

- No frontend or website.

## Gotchas

- Keep runtime dependencies listed in `requirements.txt` rather than installing them ad hoc.

## Pointers

- Python is configured in `.replit`.
